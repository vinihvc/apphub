## macOS

Run the official install script.

```bash
/bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"
```

Learn more on the [Homebrew website](https://brew.sh/).

## Windows

**WinGet** is already installed on Windows 11.

On **Windows 10**, install the latest [App Installer](https://apps.microsoft.com/detail/9nblggh4nns1) from the Microsoft Store.

If you prefer to install WinGet manually, open PowerShell or Command Prompt and run:

```bash
$progressPreference = 'silentlyContinue'
Write-Host "Installing WinGet PowerShell module from PSGallery..."
Install-PackageProvider -Name NuGet -Force | Out-Null
Install-Module -Name Microsoft.WinGet.Client -Force -Repository PSGallery | Out-Null
Write-Host "Using Repair-WinGetPackageManager cmdlet to bootstrap WinGet..."
Repair-WinGetPackageManager -AllUsers
Write-Host "Done."
```

Learn more in the [WinGet documentation](https://learn.microsoft.com/en-us/windows/package-manager/winget/).

## Linux

**Debian** and **Ubuntu** ship with **apt**.

Refresh your package index before installing software:

```bash
sudo apt update
```
